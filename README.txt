# Birthday Surprise Website ❤️

## How to personalize it

Open `script.js`.

At the top, change:

const herName = "My Love";
const yourName = "Your Name";

For example:

const herName = "Ama";
const yourName = "Bashiru";

## Add your own photos

You can later add an `images` folder and replace the memory cards with photos of you two.

## How to run it

1. Open the folder in VS Code.
2. Open `index.html` in your browser.
3. For the best experience, use the Live Server extension in VS Code.
4. Send the folder to your girlfriend or host it on GitHub Pages.
